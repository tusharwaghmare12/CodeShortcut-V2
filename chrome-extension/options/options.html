${CURSOR} & Dynamic Shortcuts Guide

Learn how cursor placement and dynamic pb / pp shortcuts work in CodeShortcut.

1. ${CURSOR} Cursor Placement

Use ${CURSOR} inside any snippet template to specify where the cursor should land after pressing TAB.

for(int i = 0; i < n; i++){\n    ${CURSOR}\n}

2. Dynamic pb and pp Shortcuts

You can append pb or pp to any expression to automatically generate method calls:

  • apb + TAB → a.push_back(|);
  • vpb + TAB → v.push_back(|);
  • cpp + TAB → c.pop_back(|);
  • arrpp + TAB → arr.pop_back(|);
